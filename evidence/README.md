# Final Competition Evidence

This directory is intentionally mostly empty in the repository template.

Populate it only with evidence generated from the final submitted commit and competition environment.

Recommended layout:

```text
evidence/
├── benchmarks/
│   ├── baseline.json
│   ├── cool.json
│   └── benchmark_comparison.json
├── traces/
│   ├── clean_demo_trace.json
│   └── degraded_demo_trace.json
└── screenshots/
    ├── aws_health.png
    ├── clean_demo.png
    └── degraded_human_review.png
```

Every final artifact should be reproducible and free of credentials, private data and unnecessary personal information.
